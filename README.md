# VK Chat Finder Bot

Русскоязычный Telegram-бот ищет сообщества VK по одному или нескольким ключевым словам и городам, затем извлекает публичные приглашения в беседы из всех строковых полей карточки сообщества и закреплённой записи.

Обычные публикации не сканируются: код использует только `groups.search`, `groups.getById` и, при наличии закрепа, `wall.getById`.

## Возможности

- выбор одного, нескольких или всех общих и личных ключевых слов;
- множественный выбор городов из встроенного справочника, ручной ввод, недавние и неповторяющиеся случайные города;
- строгая локальная проверка наличия ключа и города в названии сообщества;
- рекурсивное сканирование всех возвращённых VK полей карточки группы;
- поддержка `vk.com/join`, `vk.ru/join` и `vk.me/join`;
- доступ по белому списку с управлением через `/admin`;
- персистентная очередь поисков и восстановление после перезапуска;
- раздельная история и база каждого Telegram-пользователя;
- фильтры базы по названию, ключу, городу и наличию беседы;
- SQLite, Alembic, long polling и Docker Compose.

## Быстрый запуск

1. Скопируйте `.env.example` в `.env` и заполните:

   - `TELEGRAM_BOT_TOKEN` — токен BotFather;
   - `VK_USER_ACCESS_TOKEN` — пользовательский access token VK;
   - `ADMIN_TELEGRAM_IDS` — числовые Telegram ID администраторов через запятую.

2. Запустите:

   ```bash
   docker compose up --build -d
   ```

3. Посмотрите журнал:

   ```bash
   docker compose logs -f bot
   ```

База хранится в постоянном Docker volume `bot_data`. Файл `.env` исключён из Git и Docker build context. При локальном запуске SQLite-файл находится в `./data/bot.db`.

## Локальная разработка

```bash
python -m venv .venv
.venv/Scripts/activate
pip install -e ".[dev]"
alembic upgrade head
python -m vk_chat_bot
```

```bash

```

## Справочник городов

Встроенный снимок содержит уникальные названия городов и FIAS GUID. Одинаковые названия намеренно объединены. Снимок сформирован из открытого FIAS-производного справочника HFLabs; официальный источник адресных данных — ГАР/ФИАС ФНС.

Для обновления напрямую из распакованной официальной выгрузки ГАР:

```bash
python scripts/build_cities_from_gar.py C:/path/to/gar
```

Скрипт потоково читает `AS_ADDR_OBJ_*.XML`, оставляет активные объекты типа `г`/`город` и пересобирает `cities.json`.

## Команды

- `/start` — главное меню;
- `/search` — новый поиск;
- `/keywords` — личные ключевые слова;
- `/database` — сохранённые сообщества;
- `/history` — история запусков;
- `/cancel` — отмена активного поиска;
- `/help` — справка;
- `/admin_keywords` — управление общим словарём для ID из `ADMIN_TELEGRAM_IDS`.
- `/admin` — выдача и отзыв доступа, просмотр белого списка и управление словарём.

## Запуск через systemd

Готовый unit-файл находится в `deploy/vk-parser.service`. Он ожидает проект в `/opt/vk-parser`, виртуальное окружение в `/opt/vk-parser/.venv` и отдельного системного пользователя `vkparser`.

## Ограничения

- `groups.search` возвращает не более первых 1000 результатов на запрос; бот показывает предупреждение, когда выдача ограничена.
- Город и регион из профиля сообщества VK не используются.
- Приглашения не открываются и не валидируются, поэтому устаревшая ссылка может остаться в истории.
- SQLite-конфигурация рассчитана на один экземпляр приложения.
